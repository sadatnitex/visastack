## Objective

Every read listed in F's `read-baseline/A2.json` uses the right lifecycle condition, so an archived document never shows by default and a deleted one never shows at all, anywhere: lists, search, AI context and tools, briefs, agency views, exports, previews and downloads, processing jobs.

## Rule per read (apply and record the choice in a code comment of one line)

| Kind of read | Condition |
|---|---|
| Default lists, offers, search results, AI default context, briefs, reminders | `everydayDocumentCondition()` |
| An explicit choice (case selection, grant `document_ids`, AI connection document) | `presentDocumentCondition()` (archived stays, deleted goes) |
| Serving bytes: preview, download, Safe Copy, AI original file, signed link recheck | `presentDocumentCondition()`; a non-present document returns the same not-found as a missing one |
| Processing jobs (intake, reading, OCR, classification) | `presentDocumentCondition()`; skip quietly |
| Own-data export (`export.ts`, account export) | All present documents, archived labelled "Archived"; Recently Deleted labelled "Scheduled for removal" |
| Agency views of shared cases | `presentDocumentCondition()` (archive never revokes sharing, D6) |
| `workspace-search.ts` applicants | `everydayApplicantCondition()` |

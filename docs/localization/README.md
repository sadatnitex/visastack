# Localization source census and bn-BD register

Documentation and data only. Nothing in the product was changed. The language switch remains off and the English experience is untouched. Nothing here is released text.

| File | What it is |
|---|---|
| `VISASTACK_UI_SOURCE_CENSUS.csv` | Every string found in product source with file, lines, component, kind, evidence, placeholders, plural flags, roles, routes, state hints, guard tags, rendered confirmation, priority. Dynamic expressions are rows flagged `DYNAMIC_REQUIRES_RENDERED_CHECK`. Em dashes in strings are written `[U+2014]` |
| `VISASTACK_TRANSLATION_REGISTER.csv` | One row per de-duplicated semantic group with source ids, proposed bn-BD draft, automated checks, provenance, review state. Other locales: not started |
| `VISASTACK_PLATFORM_LANGUAGE_EVIDENCE.csv` | External English and Bengali pairs with URL, page id, date and evidence quality. Only `OFFICIAL_STRING_RESOURCE`, `DIRECT_SCREEN` and `BILINGUAL_OFFICIAL_PAGE` are product-attested |
| `VISASTACK_SEMANTIC_GUARDRAILS.md` | Language-state invariants, critical errors, prohibited substitutions, locale research notes |
| `VISASTACK_COVERAGE_REPORT.md` | Counts and gaps, generated by script |
| `VISASTACK_I18N_ENGINEERING_PROPOSAL.md` | Bounded proposal for extending `packages/i18n` |
| `review-packet/REVIEW_PACKET.md` | 20 journeys with phone screenshots in English, bn draft and an RTL layout probe |
| `data/drafts/OWNER_DECISIONS.json` | The owner's decisions of 2026-11-12 (first language, case word, digits, reviewers), applied by the register builder |
| `data/CASE_FILE_COLLISION_REVIEW.csv` | Strings where the case word and an uploaded file are both ফাইল |
| `data/` | Glossary, existing Bengali catalogue review, drafting inputs and outputs, journeys, independent review, product copy findings |
| `data/INDEPENDENT_REVIEW.md`, `data/REVIEW_RESPONSE.md` | A separate session's re-check of this work and what was done about each finding |
| `data/review-queues/` | Four queues (ordinary UI, commercial, privacy and legal, official visa requirements). Assigned to the owner; nothing is reviewed |
| `data/RELEASE_CLASSIFICATION_2026-11-12.md`, `.json` | Every group the owner's blanket approval of 2026-11-12 released or kept in English, with the reason. The register and queue `review_state` is derived from it (`tools/release-state.mjs`, `tools/apply-release-state.mjs`) |
| `data/FLAGGED_AUDIT.csv` | Disposition of each of the 231 drafts flagged at PR head bd5eb8bc |
| `data/ATTESTATION_STATUS.md` | What wording was observed, what is a language-model recommendation, what was never verified, and the research gaps |
| `data/NUMBER_DATE_FORMAT_RULES.md`, `data/NUMBER_DATE_AUDIT.csv` | Bengali number and date rules (real `Intl` output) and the audit that no identifier changed |
| `data/NAV_TERM_REVIEW.csv` | Document-label strings, to confirm the navigation term ডকুমেন্টস |
| `data/SAMPLE_KEY_CHECKS.md` | Sample rows re-opened against the real source files |
| `tools/` | Scripts that generate everything. Run `docs/localization/run-all.sh` |

The research kit named in the brief (a workbook with 189 terms, 54 phrases and 46 keys, plus three CSV files and a README) was not present in the repository or on the machine in this session, so it could not be read or used. The 46 canonical keys match the 46 English keys that exist in `packages/i18n`, which were reviewed directly.

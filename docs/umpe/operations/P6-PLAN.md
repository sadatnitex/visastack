# P6 plan: agency document requests before any traveller record (Lane C)

Branch `umpe/p6-agency-request` from `origin/umpe/contracts-necessity`. ADR 0026 D3, D4, D5, D8 bind.

1. Switch `AGENCY_COLLECTION_REQUESTS` (read with `switchOn`), off by default. Off: every service refuses as not found, agency pages and `/collect` return not found, the agency link is hidden.
2. Schema (no person-owned columns): `agency_collection_requests`, append-only `agency_collection_request_revisions` (a trigger refuses UPDATE and DELETE), `agency_collection_links` (token hash only). Migration generated with drizzle-kit as the last commit, titled `TEMP migration, lead regenerates after P1`; no code or test names its number (the test finds it by tag suffix).
3. Gates (new `access/collection-scope.ts`):
   - `AgencyCollectionScope`: minted only by `agencyCollectionPrincipal(db, accountId, organizationId)` after a live `isOrgAdmin` check and the switch; fresh for five minutes; every service calls `agencyCollectionScopeProblem` first and filters on the scope's organization id in every WHERE.
   - `CollectionLinkProof`: minted only from a raw link token (the bearer link itself); allowed callers are the `/collect` route and the notification worker (which holds the sealed link at send time). A static test pins the callers.
   - The ratchet gains a collection-table set (`agencyCollectionRequests`, `agencyCollectionRequestRevisions`, `agencyCollectionLinks`) judged against these two gates. No exceptions, no baseline. Proven red once with an ungated reader.
4. Services `packages/services/src/umpe-collection-request-*.ts`:
   - create draft (destination, purpose or route or Not Sure Yet, dates, known countries, due date, recipient hints), propose a checklist from the best fitting published official pack (`listFittingPublicPacks`, `listRequirements`, labels from `requirement-necessity.ts`), otherwise an agency checklist plainly labelled as the agency's own;
   - edit draft items (add agency items with AGENCY_ADDED provenance and Mandatory, Recommended or Optional; notes; reorder; remove agency items; official items keep their official necessity);
   - issue: verify the pack checksum, freeze items, pack checksum, brand snapshot (ACTIVE agencies only) and a SHA-256 of canonical content into the next revision; reissue appends, earlier revisions stay readable; reads re-verify the content hash;
   - links: `generateInvitationToken` and `hashInvitationToken`, 14 days, raw token returned once, a new link replaces the previous open one; revoke closes the request and every link;
   - email through `queueInvitationEmail` kind `collection` (sealed link, new event `AGENCY_COLLECTION_REQUEST_SENT`), send-time recheck through `CollectionLinkProof` (suppressed after revoke, expiry, replacement, suspended agency or removed issuer); subject and body never name the route, documents or person; agency name only when ACTIVE;
   - list with Draft, Sent, Expired, Revoked, Closed; audit events for create, issue, link, email and revoke; rate limits per actor and organization, and per network address on `/collect`.
5. Web: `apps/web/src/app/app/agency/[orgId]/collection/**` (list, new, detail with revision history, issue, copy link, WhatsApp share text with no delivery claim, email, revoke); one navigation link (admins, switch on). Public `/collect/open` sets a short httpOnly, Secure, SameSite=Lax cookie bound to the link and redirects to `/collect` (token leaves the address bar); `/collect` shows neutral branding and an honest line that responding opens in a later release; same answer for every closed link; no-referrer.
6. Two guards proven red with cp backups.
7. Verify: lint, typecheck, targeted vitest, db migration tests; `/code-review max` and `/security-review`; fix confirmed findings; zero em dashes; push only this branch.

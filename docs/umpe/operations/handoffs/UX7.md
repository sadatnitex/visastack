- Owner request (3 Nov 2026): "Add Documents" took people to the whole Documents screen, and "Upload" there showed two sections (a file card and a folder card). The owner asked for the simplest, most self-explanatory path from adding a file to the Master Profile being updated, and said go on the designed concept (boards sent the same day). This is part A of three (A one door, B results shown in place, C review and done).
- What changed:

The ways that need a choice, taking a photo and saying what kind of document it is, sit behind one quiet line, "Take a Photo, or Say What Kind of Document It Is" (the existing uploader, unchanged). Under it, "What Happens Next" in three short lines: Checked for Safety, Read for Details, You Approve. A kind in the address (`?type=`) opens that line ready.
  - Every "Add Documents" entry now lands there: the sidebar task, Home, the My Documents page button, the record hub, the profile editor, insights and the record page.

Its old anchors (`#add-document`, `#document-upload`) still land on that card, so old links keep working. The page no longer reads storage, plan limits, scanner state or upload receipts it only needed for the uploader.
- Kept exactly as before: the consent gate (core processing consent first, with the same explanation), the owner check, the safety scan before any preview, per-person scoping, upload receipts, the per-file caps, the family path, the camera, the kind choice including a name for Other, and human approval of every suggested detail.

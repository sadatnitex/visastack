# UX13 hand-back: documents list on a phone (no migration)

- Owner report (3 Nov 2026, phone screenshot of My Documents): the Manage button touched the bottom border of the file card, and the Current, Archived and Recently Deleted links were underlined like sentence links.
- Causes: the wrapper `wallet-document-manage` had no style at all, so the button sat flush under the selected file card and offset from its text; the tab links sit inside list items, where the sentence-link underline rule reaches them (the same cause as UX10).
- Fix (one `WP-UMPE-UX13` block in `globals.css`, one class in `lifecycle-tabs.tsx`): the Manage wrapper has the card's own padding so the button starts 8 px under the card and lines up with its text; the tab links carry `plain-link`, so they are not underlined. Measured with the real stylesheet at 390 px: gap 8 px, tab underline none.
- Tests: tabs are not underlined (new case in `lifecycle-tabs.test.tsx`), and the stylesheet gives the Manage wrapper padding (`lib/card-links-css.test.ts`). Whole web suite passes.
- Not verified: a real phone, dark appearance.

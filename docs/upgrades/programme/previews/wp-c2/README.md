# WP-C2 before and after

Every pair keeps its exact page size: colour and edge changes only. `13` and `14` are the account menu and the workspace switcher opened in the same page. `collapsed-rail-after-desktop.jpg` shows the current-page bar beside the icon in the collapsed sidebar.

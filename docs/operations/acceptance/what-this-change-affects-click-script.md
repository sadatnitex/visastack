# What This Change Affects: click script for the owner

Run this signed in on the live site with made-up records only. It takes about ten minutes. Each
step says what to do and what you should see. If a step shows something else, note the step
number and what you saw; that is the finding.

This script exists because the signed-in screens cannot be checked from a development machine
(there is no real sign-in there). Until it has been run, the signed-in journey is not verified.

## Before you start

You need one made-up traveller with:

- two passports (or any two documents of the same kind), both checked and current, called here
  the older one and the newer one;
- one open case that uses the older one and that you have confirmed;
- one saved detail that the same case uses, for example Employer Name.

Optional, for a fuller check: an agency you shared the older document with by name, and an agency
request you answered with the older document.

## 1. Replace a document that a case uses

1. Open Documents. On the older document open Manage, then choose Replace with a Newer Document.
   You should see the list of documents you can choose as the newer one.
2. Choose the newer one and press Continue.
   You should see the heading "Replace (the document's name)?" and, under it, "What This Change
   Affects". For a moment it may say "Working out what this change affects."
3. Read the list.
   You should see "Needs Your Action" with your open case, and a sentence that says the case
   uses this document and will ask you to choose the document and confirm again. If you set up
   the optional agency records, they appear under "Worth a Look". Nothing says an agency has
   opened or read anything. The last line says the list sends, shares and changes nothing.
4. Check that nothing has changed yet: the Replace button is still there and the older document
   is not marked Replaced.
5. Press Replace.
   You should see "Document Replaced", the line that the old document stays in your records
   marked Replaced, and the same list again, now worded as done ("still uses the earlier
   document").
6. Press "Open the Case" beside your case.
   You should land on that case, which asks you to choose the document and confirm again. Go back.

## 2. Open the review again from the documents list

1. Open Documents and select the older document (now marked Replaced).
   You should see a link "What This Change Affects" beside the Replaced label.
2. Press it.
   You should see a page titled "What This Change Affects" with the same list as in step 1.5,
   and a way back to Documents.
3. A current document that was not replaced should show no such link.

## 3. Save a changed detail

1. Open Profile and change the saved detail the case uses (for example Employer Name) to a new
   made-up value. Save.
   You should see the usual saved line and, under it, a small box "What This Change Affects"
   with a count in words (for example "1 item needs your action.") and a link "See the Full List".
2. Press "See the Full List".
   You should see the page with your case under "Needs Your Action" and a sentence that your
   earlier confirmation no longer counts.
3. Press "Open the Case".
   You should land on the case, which asks you to confirm it again.

## 4. A change that affects nothing (the control)

1. Change a saved detail that no case, agency request or share uses. Save.
   You should see only the usual saved line. No box, no alert, nothing new.
2. Replace a document that no case uses and that you never sent or shared, with a newer one.
   On the confirm step you should see one calm line: "Nothing else uses this. No action is
   needed." No alert appears at any point.

## 5. Things that must never happen

- A sentence that says an agency or a person has seen, viewed or relied on something.
- A button inside the list that sends, shares or changes anything. The list has links only.
- The older document disappearing. It stays, marked Replaced.
- The replacement or the save failing because the list could not be worked out. If the list
  cannot be shown you should see one plain line saying so, and the replacement or save still works.

## If you use Bangla

The words of this review are in English for now, also for a reader who chose Bangla. Dates
inside those English sentences use ordinary digits. That is expected until the Bangla wording is
drafted and reviewed.
